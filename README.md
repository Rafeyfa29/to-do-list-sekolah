# Aplikasi To-Do List Sekolah

Ini adalah projek tugas sekolah berupa aplikasi manajemen tugas (To-Do List) berbasis Python menggunakan antarmuka GUI (Tkinter).

## ✨ Fitur:
- **Input Tugas:** Judul, Detail, dan Deadline.
- **Auto-Save:** Data tersimpan otomatis dalam file JSON.
- **Sistem Deadline:** Menghitung sisa hari secara otomatis.
- **Reminder:** Peringatan otomatis 3 hari sebelum deadline.
- **Tandai Selesai:** Fitur untuk menandai tugas yang sudah dikerjakan.

## 🚀 Cara Menjalankan:
1. Pastikan sudah menginstal Python.
2. Download file `tugas_sekolah.py`.
3. Jalankan di terminal: `python tugas_sekolah.py`.
